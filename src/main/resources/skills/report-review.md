# Skill：report-review（报告生成规则）

## 一、这个 Skill 是做什么的

面试结束后，把本场面试的完整数据（题目、作答、评分、评语、追问）交给大模型，
生成一份**可直接展示和落库的 Markdown 总结报告**，供候选人和面试官复盘。

调用入口：`InterviewAiFacade.generateReport(...)`
数据来源：`InterviewReportDataRepository.loadContext(...)` 组装出的面试数据文本

## 二、输入

| 参数 | 说明 |
| --- | --- |
| sessionId | 面试会话 ID，拼入提示词便于 AI 理解上下文 |
| context | 本场面试的完整数据文本（逐题、逐次作答、评分与评语、追问记录） |

> `context` 超过 12000 字符会被截断，因此报告要**基于给定数据**总结，
> 不要试图补全数据里没有的信息。

## 三、输出契约（必须严格遵守）

- **只返回 Markdown 正文**，不要返回 JSON，不要附加额外解释。
- 必须严格包含以下四个章节，标题文字与顺序不可改动：

```markdown
## 一、总体评价
## 二、逐题点评
## 三、能力维度分析
## 四、改进建议
```

## 四、各章节写法要求

### 一、总体评价

- 3-5 句，说明整体表现、是否达到岗位基本要求、最突出的优点和最主要的问题。
- 必须给出明确结论（如"整体达到初级后端岗位要求，但深度不足"），不要和稀泥。

### 二、逐题点评

- **一道题一条**，按题号顺序排列，格式建议：

```markdown
### 第 1 题：<题目摘要>
- 得分：<分数>
- 作答要点：<候选人答了什么>
- 点评：<对在哪、缺什么>
```

- 追问记录并入对应题目的点评里，不单独开章节。
- 追问作答不重复计入题序，只作为该题表现的补充证据。

### 三、能力维度分析

- 从数据中归纳 3-5 个能力维度（如 Java 基础、并发、数据库、中间件、项目经验、表达）。
- 每个维度给出：表现结论 + 支撑证据（引用具体题号或作答片段）。
- 用列表或表格呈现，**不要写空泛的形容词**。

### 四、改进建议

- 3-5 条，**可执行**：明确"学什么、练什么、怎么验证"。
- 按优先级排序，优先解决影响最大的短板。
- 不要写"多看书""多练习"这类没有信息量的建议。

## 五、规则与禁止事项

1. **只依据给定数据**：不得编造数据中不存在的经历、题目、分数或结论。
2. **不重复数据原文**：不要把 context 整段抄进报告，要做归纳和判断。
3. **分数一致**：报告中引用的分数必须与数据中的评分一致，不得自行改分。
4. **语气客观**：对事不对人，不评价性格、学历、年龄等无关维度。
5. 不要输出 ``` 之外的 JSON、不要输出"以下是报告："之类的开场白。
6. 不要缺少任何一个章节，也不要新增第五节。
